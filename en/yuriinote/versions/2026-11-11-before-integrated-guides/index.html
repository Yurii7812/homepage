YuriiNote User Guide

Step-by-step usage. Button labels and placement can vary by version. Features in PR #8 are not yet merged.

Start

On first launch, create a vault or open an existing folder. Use the folder button to change it. Changes save automatically; check the save status at the top.

Notes

Select + New → Note (without ID). Use Assign ID to enter an ID or choose branch/parallel. Click the ID to copy it; use ⋯ → Change/remove ID to edit it. Ctrl+N creates an unnumbered note, Ctrl+B a branch, Ctrl+H a parallel note.

Paper

Use the Paper tab to view paper notes. Choose Scan import to assign paper IDs to images. Set View/Search to Paper only to restrict the list and search. Search the Index for keywords and the physical note ID.

Indexes

Search keywords in the Index tab. Use + Keyword on a note, then + Topic Index to add or create an index. A red dot above an ID marks its Topic Index. Select Edit and write one keyword and ID per line. Use ^ for a broader concept, + for another Topic Index, = for a summary; the type selector is also available. Type : to search and insert an existing note (in-development PR #8).

Search and links

The main search shows Index, Topic Index, then notes. In a note, type : to search references; Enter inserts a prefix reference, Shift+Enter a postfix, and Esc cancels. :1a links to a note, 1a: references its entirety, and 1a(1) targets a numbered passage.

Chat memos

Click the chat-bubble icon on the left. Enter sends; Shift+Enter inserts a newline. Select or create a topic. Right-click a memo to reply, link context, edit, copy, delete, or turn it into a note. Multiple memos can also be converted. Journal-topic messages appear in the journal.

Journal and records

Click the journal icon and open Today's Journal, or choose an earlier date. Use + ⚙ to add and organize record types such as dreams and work. The journal day changes at 5 a.m. Paper journal pages can be imported through the scan workflow.

Roleplay

Choose + New → Roleplay Chat. Add characters, select one above the input or switch with Tab. Enter sends, ↩ replies, @ mentions a character, and ❝ Quote inserts notes or dialogue from another conversation.

Canvas

Choose + New → Canvas. Click empty space to create a text box, use ↗ Line to connect boxes, drag to move, Ctrl+wheel to zoom, and double-click a line to label it.

Graph, cards, mandala

Use the graph icon to inspect parent/child and reference links. Use the cards icon for a Keep-style editable overview. The mandala view provides 3×3 and 9×9 layouts.

Attachments and export

Use 📎 Attach, drag-and-drop, or paste to add images and files. Choose ☑ Select for multiple notes and Export to preview or copy temporary Markdown (it does not write an export file).

Tabs, editing and deletion

Ctrl+T opens a tab and Ctrl+W closes it. Ctrl+click or middle-click opens in another tab. Edit Markdown headings, lists, checkboxes, and tables. Deleted notes move to Trash; Esc exits multi-selection.

Mobile import and updates

Use ⋯ → Install app on phone (USB) or Import phone memos (USB), with ADB available. Update via ⋯ → Check for updates or YuriiNote --update in a terminal.
