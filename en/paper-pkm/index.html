PAPER NOTES & THE DOUBLE INDEX · November 13, 2026 edition

A Visual Guide to Paper Knowledge Management

Write first, before designing a classification. Give notes IDs based on their relationship, then find them through a Global Index and Topic Indexes. This guide works entirely on paper. Keep long arguments and unfinished thinking on A4 sheets; there is no need to split them into atomic notes.

1. Write first and assign an ID

Place A4 paper upright and write freely in blue, leaving the upper left clear. A date in the upper right can help. After writing, consider the relationship to existing notes and write the sheet’s own ID in blue at the upper left. Keep long prose, drawings, lists, and unfinished thinking as they are.

Choose IDs by content: a note relates to, broadens, or deepens another. They are not assigned solely in writing order. The tree below is one possible arrangement; related material does not all have to fit in one branch.

2. Connect notes with arrows

Write referenced IDs and arrows in red. ->1a means the current passage continues in 1a; 1a-> means the current passage continues from 1a. Multiple destinations can be written ->1a, 2, 3.

Position numbers such as (1) and (2) identify particular places in text; they are separate from note IDs. Underline the original number in red. When a particular place matters, write ->2(3); normally an arrow and ID are enough.

3. Carry a small notebook

Carry a small paper notebook and write ideas as they occur. When beginning a new page, give it a page number yourself. In this notebook, page numbers serve as link IDs. Position numbers are optional. Later transfer useful material to a formal A4 note. Since the notebook may be discarded, do not ordinarily make references from formal notes back to it.

4. Create Topic Indexes

Once notes accumulate and become hard to find, make a Topic Index on A4. At the upper left write the starting note ID followed by a hyphen and index number. Inside, write keywords and destination IDs. Keywords are blue; referenced IDs are red. Choose a useful level of detail after seeing the notes; do not create indexes without a need.

1-1 is the first index based on note 1, and 1-2 is another based on the same note. 1c-1 is based on note 1c. One starting ID can have multiple indexes. If an index needs several sheets, keep the same index ID and add a page number to distinguish its pages.

5. Add a broader topic later

A broad category such as Religion need not exist at the start. Read a book on Buddhism, create a Buddhism index when useful, and add a Religion index later if needed. Use a red ↑ for a direct broader Topic Index. Subtopics generally need no special symbol. Related indexes can be stored near one another.

6. Keep books separate and index them together

As a rule, start each book in a separate Folgezettel series. Begin Book A at 1 and Book B at 2; related content does not have to be forced into the same branch. A general Buddhism index can reference notes from both series.

7. Make a developed branch independent

When a branch grows extensively and becomes specialized or advanced, it can start a new independent ID. For example, create 2 from multiplication at 1c, then write subsequent material mainly at 2, 2a, and 2b. Do not delete or move 1c or its existing notes.

8. Create and divide the Global Index

The Global Index is the overall entry point: keywords and their IDs on A4 sheets. Write the range covered at upper left in blue, order Japanese keywords by kana and English keywords alphabetically, and write referenced IDs in red. A red dot above an ID marks an independently developed topic.

When a sheet fills, first sort all registered keywords alphabetically. Divide that actual ordered list into four groups with roughly similar numbers of entries, and copy each group onto a new A4 index sheet. Use the first word of each group as a boundary and write the range at the upper left. For example: Arithmetic, Buddhism | Growth, Journal | Knowledge, Links | Multiplication, Religion. The second sheet covers Growth up to, but not including, Knowledge. The division follows the words you have, not equal segments of the alphabet.

A boundary word belongs on the sheet that begins with it; words before it belong on the preceding sheet. The first sheet also covers new words before its first entry, and the last sheet covers words after its last entry. This leaves no gaps or overlaps. Leave room for additions. If an insertion cannot fit in order, rewrite that range in order without rewriting the other ranges.

When a range fills again, sort its words, divide them into four groups, and replace only that range with four sheets. The new ranges inherit the original range’s outer boundaries. Check the number, order, and IDs after copying. Only the index ranges are divided; do not cut the A4 sheets.

9. File and find notes

File ordinary notes in Folgezettel order in A4 clear folders: for example 1, 1a, 1b, 1c, 1c1, 2, 2a. Add folders as needed and use ID tabs to find sections. Keep related Topic Indexes close together where they are easy to find. Put the date at the upper left of diary sheets and keep them in a separate clear folder.

To find a note, look up a keyword in the Global Index and follow its ID to a note or Topic Index. From the Topic Index, find the individual note; follow continuation arrows when useful.

10. Quick reference

Ordinary notes | Write freely on A4; assign IDs by relationship. |
Index IDs | Starting ID–number: 1-1, 1-2, 1c-1, 2-1. Several per starting ID are allowed. |
When to index | After writing, when useful. |
Global Index | A4 in keyword order; split a full range into four according to the entries. |
Red dot | Above an independently developed ID. |
↑ | Direct broader Topic Index. |
↳ / ↰ | Independent destination / origin; distinct from general association. |
☆ | General association: a one-stroke star. |
○ | Summary, progress, etc. Example: ○ Summary 1a; ○ Progress 1b. |
->ID / ID-> | From current passage to continuation / from the named ID to the current passage. |
(n) | Position number. Underline the original in red; specify a position only when useful. |
Blue / red | Body, keywords, and the sheet’s own upper-left ID in blue. Referenced IDs and index symbols in red. |
Pocket notebook | Page numbers serve as link IDs. Temporary; formal notes generally do not point back. |
Storage | A4 clear folders; a separate folder for the diary. |

Start with paper and a pen. Write one sheet, then let the indexes grow as you need them.
