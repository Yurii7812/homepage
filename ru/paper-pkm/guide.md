# Иллюстрированное руководство по управлению знаниями на бумаге

<div id="benefits"></div>

Сначала пишите, не определяя классификацию заранее. Присваивайте заметкам ID в зависимости от их связей и находите их через глобальный и тематические указатели. Это практическое руководство по системе двойного указателя, работающей полностью на бумаге. На листах A4 можно сохранять длинные рассуждения и незавершённые мысли; делить их на атомарные заметки необязательно.

## 1. Сначала записать, затем присвоить ID

Расположите лист A4 вертикально и свободно пишите синим, оставив верхний левый угол пустым. Удобно поставить дату в правом верхнем углу. Закончив запись, подумайте о её связи с существующими заметками и напишите синим собственный ID листа в левом верхнем углу. Длинные тексты, рисунки, списки и незавершённые мысли можно оставить как есть.

Выбирайте ID по содержательным связям: заметка связана с другой, расширяет или углубляет её. ID определяются не просто порядком записи. Ниже показан пример ветвления; не нужно помещать всё связанное содержание в одну ветвь.

## 2. Соединять заметки стрелками

ID ссылок и стрелки пишите красным. `->1a` означает, что текущий текст продолжается в 1a; `1a->` — что текущий текст продолжает 1a. Несколько продолжений можно указать так: `->1a, 2, 3`.


<figure><div class="sheets"><div class="sheet"><div class="sheet-title"><span class="own">1</span></div>Мысль о дробях. <span class="ref">-&gt;1a</span></div><div class="sheet"><div class="sheet-title"><span class="own">1a</span></div><span class="ref">1-&gt;</span> Продолжение мысли о дробях.</div></div><figcaption>Текст в 1 слева продолжается в 1a справа. Обозначение обоих концов позволяет увидеть связь с любого листа.</figcaption></figure>


Номера позиций, например `(1)` и `(2)`, обозначают конкретные места текста и отличаются от ID заметок. Подчёркивайте исходный номер красным. Если нужно указать конкретное место, пишите `->2(3)`; обычно достаточно стрелки и ID.

## 3. Носить с собой маленький блокнот

Носите с собой маленький бумажный блокнот и записывайте мысли по мере их появления. Начиная новую страницу, самостоятельно присваивайте ей номер. В этом блокноте номера страниц служат ID ссылок; при необходимости можно использовать и номера позиций. Позднее переносите содержимое в постоянные заметки A4. Поскольку блокнот можно выбросить, обычно не создавайте обратных ссылок из постоянных заметок на него.

## 4. Создавать тематические указатели

Когда заметок становится много и их трудно найти, создайте тематический указатель на A4. В верхнем левом углу запишите ID исходной заметки, дефис и номер указателя. Внутри запишите ключевые слова с ID ссылок. Ключевые слова — синим, ID ссылок — красным. Выбирайте степень детализации по имеющимся заметкам и не создавайте ненужных указателей.

`1-1` — первый указатель на основе заметки 1, `1-2` — другой указатель с той же основой. `1c-1` основан на заметке 1c. На основе одного ID можно создавать несколько указателей. Если указатель занимает несколько листов, сохраняйте его ID, добавляя номера страниц.

## 5. Добавлять более широкую тему позднее

Не нужно с самого начала создавать широкую категорию вроде «Религия». Прочитайте книгу о буддизме, при накоплении заметок создайте указатель по буддизму, а при необходимости позднее добавьте указатель по религии. Красной стрелкой `↑` обозначайте непосредственно вышестоящий тематический указатель. Для подчинённых тем специальный символ обычно не нужен. Связанные указатели можно хранить рядом.

## 6. Вести записи по книгам отдельно и связывать общим указателем

Как правило, начинайте записи по каждой книге с отдельной серии Folgezettel. Если книга A начинается с 1, а книга B — с 2, не нужно помещать их в одну ветвь даже при сходстве содержания. Общий указатель по буддизму может ссылаться на заметки из обеих серий.

## 7. Выделять развитую ветвь в самостоятельную серию

## 8. Создавать и разделять глобальный указатель

Глобальный указатель — общий вход: ключевые слова и соответствующие ID на листах A4. В верхнем левом углу синим укажите диапазон слов, японские слова располагайте по порядку каны, английские и русские — по алфавиту. ID ссылок пишите красным. Красная точка над ID обозначает самостоятельно развившуюся тему.

Когда лист заполнится, сначала расположите все зарегистрированные слова по алфавиту. Разделите полученный список на четыре группы с примерно одинаковым числом записей и перепишите каждую на новый лист A4. Границей служит первое слово каждой группы; укажите диапазон в левом верхнем углу. Например: Арифметика, Буддизм | Дневник, Знания | Развитие, Религия | Связи, Умножение. Второй лист охватывает слова от «Дневник» до «Развитие», не включая последнее. Деление определяется имеющимися словами, а не равными частями алфавита.

Граничное слово входит в диапазон, который с него начинается; предшествующие слова относятся к предыдущему листу. Первый лист охватывает также новые слова перед первой записью, а последний — слова после последней записи. Таким образом, нет пропусков или пересечений. Оставляйте свободное место для дополнений. Если вставить слово в нужном порядке невозможно, перепишите только этот диапазон, не трогая остальные.

Когда какой-либо диапазон снова заполнится, расположите его слова по порядку, разделите на четыре группы и замените только этот диапазон четырьмя листами. Новые диапазоны наследуют внешние границы прежнего диапазона. После переписывания проверьте количество, порядок и ID. Делятся диапазоны указателя, а не разрезаются листы A4.

## 9. Хранить и находить записи

Храните обычные заметки в прозрачных папках A4 в порядке Folgezettel: например, 1, 1a, 1b, 1c, 1c1, 2, 2a. При увеличении объёма добавляйте папки и при необходимости используйте закладки с ID. Связанные тематические указатели храните рядом, чтобы их было легко найти. В левом верхнем углу дневниковых записей указывайте дату и храните их в отдельной прозрачной папке.

## 10. Краткая памятка

| | |
|---|---|

| Обычные заметки | Свободно пишите на A4, присваивайте ID по содержательным связям. |

| ID указателей | Исходный ID–номер: 1-1, 1-2, 1c-1, 2-1. Допустимо несколько указателей на один исходный ID. |

| Когда создавать указатель | После записи, по мере необходимости. |

| Глобальный указатель | A4, ключевые слова по алфавиту; делите заполненный диапазон на четыре части по распределению записей. |

| Красная точка | Над ID самостоятельно развившейся темы. |

| ↑ | Непосредственно вышестоящий тематический указатель. |

| ↳ / ↰ | Самостоятельная серия / её источник; отличается от общей связи. |

| ☆ | Общая связь: звезда, нарисованная одним движением. |

| ○ | Резюме, прогресс и т. д. Например: ○ Резюме 1a; ○ Прогресс 1b. |

| ->ID / ID-> | От текущего текста к продолжению / от указанного ID к текущему тексту. |

| (n) | Номер позиции. Исходный номер подчёркивается красным; позицию указывайте только при необходимости. |

| Синий / красный | Текст, ключевые слова и собственный ID листа вверху слева — синим; ID ссылок и символы указателей — красным. |

| Карманный блокнот | Номера страниц служат ID ссылок. Временный; постоянные заметки обычно не ссылаются на него. |

| Хранение | Прозрачные папки A4; для дневника — отдельная папка. |

Начать можно с бумаги и ручки. Заполните первый лист, а указатели развивайте по мере необходимости.
