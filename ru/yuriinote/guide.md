# Руководство по работе с YuriiNote

Пошаговые инструкции. Названия и расположение кнопок могут различаться в зависимости от версии приложения. Функции PR #8 пока не интегрированы.

## Начало работы

При первом запуске создайте хранилище (vault) или откройте существующую папку. Её можно изменить кнопкой папки в правом верхнем углу. Содержимое сохраняется автоматически; состояние сохранения отображается вверху.

## Заметки

Выберите «+ New» → «Note (without ID)». Через «Assign ID» можно задать идентификатор напрямую, создать ветвь или параллельную запись. Нажатие на ID копирует его. Через ⋯ → «Change/remove ID» его можно изменить. Ctrl+N создаёт заметку без ID, Ctrl+B — ветвь, Ctrl+H — параллельную запись.

## Бумажные заметки

На вкладке Paper слева отображаются бумажные заметки. Через «📷 Scan import» присвойте изображению бумажный ID. В меню View/Search выберите Paper only, чтобы ограничить список и поиск бумажными заметками. Найдите ключевое слово в Index, чтобы определить ID физической записи.

## Указатели

Ищите ключевые слова на вкладке Index слева. В заметке используйте + Keyword для регистрации, а + Topic Index — для добавления в указатель или его создания. Красная точка обозначает вход в тематический указатель соответствующего ID. В режиме Edit записывайте по одному ключевому слову и ID на строку. Типы ссылок: ^ — более широкое понятие, + — другой тематический указатель, = — резюме. Тип также можно выбрать в меню. Двоеточие в редакторе позволяет искать и добавлять существующие заметки (разрабатываемая функция PR #8).

## Поиск и ссылки

В верхнем поле поиска результаты отображаются в порядке Index → Topic Index → заметки. В обычной заметке введите : для поиска ссылок; Enter вставляет ссылку перед текстом, Shift+Enter — после него, Esc отменяет действие. :1a — ссылка на заметку, 1a: — ссылка на неё целиком, 1a(1) — на пронумерованный фрагмент заметки.

## Чат-заметки

Нажмите значок диалога слева. Enter отправляет сообщение, Shift+Enter переносит строку. Можно выбрать или создать тему. Щелчок правой кнопкой по записи позволяет ответить, связать контекст, редактировать, копировать, удалить или преобразовать её в заметку. Можно также преобразовать несколько выбранных записей. Сообщения темы дневника отражаются в дневнике.

## Дневник и записи

Нажмите значок дневника слева и откройте Today's Journal. Выберите дату для просмотра предыдущих дней. Через + ⚙ добавляйте и организуйте виды записей, например сны и работа. День в дневнике меняется в 5 утра. Бумажный дневник также можно добавить через импорт сканов.

## Ролевой чат

Выберите + New → Roleplay Chat. Добавьте персонажей и переключайтесь между ними нажатием на имя над полем ввода или клавишей Tab. Enter отправляет реплику, ↩ отвечает на неё, @ упоминает персонажа. Через ❝ Quote можно цитировать заметки или реплики из других разговоров.

## Холст

Выберите + New → Canvas. Нажмите на пустое место, чтобы создать текстовый блок, и используйте ↗ Line для соединения блоков. Перетаскивайте блоки для перемещения, масштабируйте с помощью Ctrl+колёсико мыши, дважды щёлкните по линии для добавления подписи.

## Граф, карточки и мандала

Значок графа слева показывает родительские, дочерние и ссылочные связи заметок. Значок карточек открывает редактируемый обзор в стиле Keep. Значок мандалы открывает сетки 3×3 и 9×9.

## Вложения и экспорт

Добавляйте изображения и файлы через 📎 Attach, перетаскивание или вставку. Через ☑ Select слева выберите несколько заметок, затем Export для просмотра и копирования временного Markdown (экспортный файл не сохраняется).

## Вкладки, редактирование и удаление

Ctrl+T открывает вкладку, Ctrl+W закрывает её. Ctrl+щелчок или средняя кнопка мыши открывают запись в другой вкладке. Можно редактировать заголовки, списки, флажки и таблицы Markdown. Удалённые заметки перемещаются в корзину; Esc отменяет множественный выбор.

## Телефон и обновления

Используйте ⋯ → Install app on phone (USB) или Import phone memos (USB); требуется ADB. Для обновления выберите ⋯ → Check for updates или выполните YuriiNote --update в терминале.
