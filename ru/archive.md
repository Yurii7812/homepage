# Архив

Предыдущие работы и материалы

[Gnosis](https://github.com/Yurii7812/gnosis)  
Инструмент управления личными знаниями (PKM): запись заметок Markdown в настоящем Vim и их развитие с помощью связей. Поддерживает японский и английский языки, доступны установщики для Linux, macOS и Windows.

[Иллюстрированное руководство по управлению знаниями на бумаге](paper-pkm/guide.md)  
Способ связывать заметки на листах A4 при помощи идентификаторов Folgezettel и двойного указателя.

[YuriiNote — GitHub](https://github.com/Yurii7812/YuriiNote) · [Руководство на японском](../ja/yuriinote/guide.md) · [на английском](../en/yuriinote/guide.md) · [на русском](yuriinote/guide.md)  
Настольное приложение для совместного управления бумажными и цифровыми заметками, указателями, чат-заметками и дневниками.
